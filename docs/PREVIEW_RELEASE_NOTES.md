# Interpreter Trainer — direct access

- Opens straight into the training studio, without email or Facebook sign-in.
- Keeps practice and encrypted conversations on the device.
- Uses a no-login AI backend for streaming chat and evaluations, with cancellation, bounded requests and provider fallback before output begins.
- Removes Firebase and Facebook SDKs and configuration requirements.

AI requires the updated backend and a working server-side model provider. A configured HTTPS endpoint and live verification are required before publishing a working AI release. Existing account-owned data is preserved separately; no automatic account-data migration is performed.
